# 실행기 (유튜브 쇼츠 제작)

FIELDNOTE 작업판의 "⚡ 이 주제 제작" 버튼이 이 맥에서 실제 작업을 돌리게 해 주는 프로그램이에요.

## 켜는 법
1. `실행기 켜기.command` 를 더블클릭
2. "켜졌어요 · 이 창을 닫지 마세요" 가 보이면 끝. 작업판(크롬)으로 돌아가면 돼요.
3. 크롬이 "로컬 네트워크 접근"을 물으면 **허용**.

## 다른 맥에 설치·업데이트
1. 저장소를 `git pull` 해요.
2. 저장소의 `runner/설치·업데이트.command` 를 더블클릭해요. (처음 설치도, 새 버전으로 바꾸는 것도 똑같아요)
3. 크롬이 "로컬 네트워크 접근"을 물으면 **허용**.
- 필요한 프로그램(yt-dlp, ffmpeg)이 없으면 알아서 깔아 줘요. node 만 먼저 nodejs.org 에서 설치하세요.
- 옛 실행기는 `~/Desktop/유투브/실행기-옛날-날짜` 로 보관하고, 내 그림체(`styles.json`)와 AI 키(`anthropic-key.txt`)는 그대로 둬요.
- 에피소드 폴더는 맥마다 따로예요. 서로 안 섞여요.
- 실행기 코드를 고칠 때는 **저장소의 `runner/` 폴더에서** 고치세요. 바탕화면의 실행기 폴더는 설치된 복사본이라, 거기서 고치면 다음 업데이트 때 덮어써져요.

## 끄는 법
켜진 터미널 창에서 `Ctrl+C`, 또는 창을 닫으면 꺼져요. 진행 중이던 단계는 다음에 켤 때 "실패"로 보이니 다시 실행하면 돼요.

## 파일 위치
- 에피소드 폴더: `~/Desktop/유투브/에피소드/<제목>/`
  - `소스.json`, `원본/`, `클립/`, `편집/`(대본.md · 편집계획.json · 가편집.mp4 · 완성본.mp4 · 최종본.mp4 · 녹음/), `업로드/`(업로드.txt · 업로드.json · 영상.mp4 · 썸네일.jpg), `로그/`
- 위치를 옮기려면(예: iCloud Drive): 환경변수 `FIELDNOTE_RUNNER_DATA=/원하는/폴더` 를 주고 켜세요.
- 상태는 폴더 안 `state.json` 에 저장돼서 껐다 켜도 이어져요.

## 단계
소스 확인 → 소스 받기 → **대본(여기서 멈춤, 직접 확인)** → 편집 계획 → 가편집 → 자막·효과 → 목소리·음악 → 업로드 패키지
- 대본이 멈추면 `편집/대본.md` 를 열어 읽고 고친 뒤 "대본 확인 완료 · 계속"을 누르세요. "[여기에 대사]" 가 남아 있으면 넘어가지 않아요.
- 목소리·음악은 작업판의 "녹음·음악 열기"에서 줄마다 녹음하고, "목소리·음악 넣기"를 누르세요.
- 유튜브에 직접 올리지는 않아요. `업로드/` 의 내용을 YouTube Studio 에 복사해 올리세요.

## 음악 넣는 곳
- 배경음악: `~/Desktop/유투브/소리/BGM/` (mp3·m4a·wav 등)
- 시그니처 소리: `~/Desktop/유투브/소리/시그니처/`
- 넣으면 녹음 칸의 목록에 바로 떠요. 저작자 표시가 필요 없는 곡만 쓰세요. 목소리가 나올 때 음악은 자동으로 작아져요.

## 대본 AI 키 (선택)
- 없어도 돼요. 없으면 빈 양식(`대본.md`)과 Claude 채팅에 붙여 넣을 요청문(`대본-요청.txt`)을 만들어요.
- 있으면 대본을 자동으로 써 줘요: 이 폴더에 `anthropic-key.txt` 파일을 만들고 첫 줄에 키만 붙여 넣으세요. (또는 환경변수 `ANTHROPIC_API_KEY`)

## 인스타 그림 (ChatGPT Codex)
- 작업판의 인스타 3개 계정이 이 실행기로 그림을 그려요. ChatGPT 앱의 Codex 로그인을 그대로 써요 (API 키 없음). 한 장에 1~3분, 한 장씩 차례로.
- 그림체 = 내가 만든 그림 묶음 (`~/Documents/Codex/instagram-toon/*`, `otter-couple-assets/*`). 이름·설명은 `styles.json` 에서 고쳐요. 새 그림체는 작업판에서 "이 그림을 새 스타일로 저장".
- 결과 그림: `~/Documents/Codex/instagram-toon/fieldnote/<계정>/<작업>/NN-시각.png` (옛 버전도 남아요).
- 주소: `GET /img/styles`, `POST /img/styles`, `POST /img/generate`, `GET /img/jobs?projectId=`, `POST /img/cancel`, `GET /file?path=…[&thumb=1]` (읽기 전용 폴더만).
