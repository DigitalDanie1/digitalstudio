# 실행기 (유튜브 쇼츠 제작)

FIELDNOTE 작업판의 "⚡ 이 주제 제작" 버튼이 이 맥에서 실제 작업을 돌리게 해 주는 프로그램이에요.

## 켜는 법
1. `실행기 켜기.command` 를 더블클릭
2. "켜졌어요 · 이 창을 닫지 마세요" 가 보이면 끝. 작업판(크롬)으로 돌아가면 돼요.
3. 크롬이 "로컬 네트워크 접근"을 물으면 **허용**.

## 다른 맥에 설치·업데이트
1. 저장소를 `git pull` 해요.
2. 저장소의 `runner/설치·업데이트.command` 를 더블클릭해요. (처음 설치도, 새 버전으로 바꾸는 것도 똑같아요)
3. 크롬이 "로컬 네트워크 접근"을 물으면 **허용**.
- 필요한 프로그램(yt-dlp, ffmpeg)이 없으면 알아서 깔아 줘요. node 만 먼저 nodejs.org 에서 설치하세요.
- 옛 실행기는 `~/Desktop/유투브/실행기-옛날-날짜` 로 보관하고, 내 그림체(`styles.json`)와 AI 키(`anthropic-key.txt`)는 그대로 둬요.
- 에피소드 폴더는 맥마다 따로예요. 서로 안 섞여요.
- 실행기 코드를 고칠 때는 **저장소의 `runner/` 폴더에서** 고치세요. 바탕화면의 실행기 폴더는 설치된 복사본이라, 거기서 고치면 다음 업데이트 때 덮어써져요.

## 자동으로 켜 두기 (추천)
`자동실행 켜기.command` 를 한 번 더블클릭하면 맥에 로그인할 때마다 실행기가 뒤에서 켜져요 (터미널 창 없음). 끄려면 `자동실행 끄기.command`.

## 작업판 순서 (7칸)
원본 링크 → 편집 스타일 선택 → 링크 영상 다운 → 1차 편집 → 피드백 → 2차 편집 → 최종 편집안 다운로드
- 1차 편집: 구간을 넣으면 자르기·스타일·자막(대본이 있으면)·소리까지 한 번에 만들어요. 슬로우는 구간 끝에 `x0.5` (예: `0:30-0:34x0.5`).
- 피드백: 고칠 점을 적고 Claude 요청문을 복사 → Claude 답을 붙여 넣기 (AI 키가 있으면 바로 반영). 구간·대본을 직접 고쳐도 돼요.
- 매트 스토리 룩 대본: `> 배너: 위 줄 / 아랫줄 ㄷㄷ`, `> 출처: 채널`, `[태그] 선수 (나라) / 대회`, `[점수] 4 : 0 / 설명`, `*강조*`. 원본 경기 소리 + 배경음악.

## 레슬링 작업판: AI 편집 (7칸)
원본 링크 → 하이라이트 1차 컷 → 스타일 선택 → 스타일 입히기 → 자막 → 인트로·아웃트로 → 다운로드
- 판단은 이 맥의 **Claude Code**(`claude -p`, 구독)가 해요. API 키 필요 없음. 맥에서 `claude` 가 로그인돼 있어야 해요.
- 단계마다 `~/.claude/skills` 의 스킬 규칙을 먼저 읽어요: 1차 컷 = shorts-blueprint·edit-plan-sheet / 스타일 = source-check-research(조사 → `조사/research.md`)·shorts-blueprint / 자막 = shorts-blueprint.
- 인트로·아웃트로는 모든 단계에서 후크: 첫 컷 intro·마지막 컷 outro, 위 2줄 제목, 0초 자막·마지막 자막.
- 결과: `편집/AI컷.json` · `AI1차컷.mp4` → `AI완성.json` · `AI스타일본.mp4` → `AI완성.mp4`. 자막을 직접 고치려면 `AI완성.json` 을 고치고 "자막 다시 쓰기" 대신 그 파일로 다시 그리면 돼요.
- 인트로(2.2초)·아웃트로(3.2초): Claude 가 후크 문장을 쓰고, 채널 로고 `~/Desktop/유투브/브랜드/matstory_logo.png` 와 @matstoryhq 를 넣어 그려요. 결과: `AI인트로.mp4` · `AI아웃트로.mp4` · 붙인 `AI최종.mp4`.
- 배경음악: `~/Desktop/유투브/소리/BGM/` 의 첫 파일을 원본 경기 소리 아래에 깔아요.

## 끄는 법
켜진 터미널 창에서 `Ctrl+C`, 또는 창을 닫으면 꺼져요. 진행 중이던 단계는 다음에 켤 때 "실패"로 보이니 다시 실행하면 돼요.

## 파일 위치
- 에피소드 폴더: `~/Desktop/유투브/에피소드/<제목>/`
  - `소스.json`, `원본/`, `클립/`, `편집/`(대본.md · 편집계획.json · 가편집.mp4 · 완성본.mp4 · 최종본.mp4 · 녹음/), `업로드/`(업로드.txt · 업로드.json · 영상.mp4 · 썸네일.jpg), `로그/`
- 위치를 옮기려면(예: iCloud Drive): 환경변수 `FIELDNOTE_RUNNER_DATA=/원하는/폴더` 를 주고 켜세요.
- 상태는 폴더 안 `state.json` 에 저장돼서 껐다 켜도 이어져요.

## 단계
소스 확인 → 영상 받기 → 구간 자르기 → 편집 계획 → 가편집 → 자막 자동화 → 이펙트 → **대본(여기서 멈춤, 직접 확인)** → 목소리·음악 → 업로드 패키지 (10단계)
- 대본이 멈추면 `편집/대본.md` 를 열어 읽고 고친 뒤 "대본 확인 완료 · 계속"을 누르세요. "[여기에 대사]" 가 남아 있으면 넘어가지 않아요.
- 목소리·음악은 작업판의 "녹음·음악 열기"에서 줄마다 녹음하고, "목소리·음악 넣기"를 누르세요.
- 유튜브에 직접 올리지는 않아요. `업로드/` 의 내용을 YouTube Studio 에 복사해 올리세요.

## 음악 넣는 곳
- 배경음악: `~/Desktop/유투브/소리/BGM/` (mp3·m4a·wav 등)
- 시그니처 소리: `~/Desktop/유투브/소리/시그니처/`
- 넣으면 녹음 칸의 목록에 바로 떠요. 저작자 표시가 필요 없는 곡만 쓰세요. 목소리가 나올 때 음악은 자동으로 작아져요.

## 대본 AI 키 (선택)
