# FIELDNOTE 콘텐츠 스튜디오

`fieldnote-studio.html`을 Chrome 또는 Safari에서 열면 됩니다. 설치나 인터넷 연결 없이 사용할 수 있는 단일 HTML입니다.

1. **새 소재**에서 실제 경험·생각·참고 자료를 기록합니다.
2. **경험·소재함 → 원고 틀 만들기**에서 채널을 선택합니다.
3. **원고 편집**에서 본문과 출처를 작성하고 저장합니다.
4. **검수함으로 보내기**로 검수 대기 상태를 지정합니다.
5. 검수 항목 3개를 확인하고 **검수 완료·승인**을 누릅니다.
6. **Markdown**으로 원고를 내보냅니다.

데이터는 현재 브라우저의 로컬 저장소에 저장됩니다. 다른 브라우저나 파일 경로에서는 저장 공간이 다를 수 있습니다. **설정·데이터 → JSON 백업**으로 정기적으로 보관하고, JSON 복원으로 가져오세요. 복원은 현재 데이터를 교체합니다.

처음 제공되는 내용은 모두 예시입니다. 설정에서 예시 데이터만 지울 수 있습니다. 원고를 수정하면 검수 항목이 초기화되고, 저장 시 기존 승인은 해제됩니다.

이 버전은 편집·검수용 로컬 도구입니다. AI 원고 생성, 웹 조사, 이미지·영상 생성, 계정 로그인, 예약 및 실제 SNS 발행 기능은 연결되지 않았습니다. ‘원고 틀 만들기’는 메모와 편집 가이드를 담은 텍스트 틀을 생성합니다. 검수 체크는 사용자의 확인이며 자동 사실 검증이 아닙니다.

## 키워드·주제 분석

사이드바의 **키워드·주제**에서 플랫폼을 선택하세요. 관심 주제는 별 버튼으로 켜고 끄며, 관리 화면에서 추가하거나 이름을 수정할 수 있습니다.

- 네이버: 검색어별 검색 유입 횟수
- 유튜브: 검색 유입 조회수 또는 주제별 조회수
- 인스타그램: 주제별 조회·저장·공유 횟수

**유입 기록**에서 계정 하나의 월별 전체 합계, 검색어 또는 주제, 지표, 관심 주제 분류, 근거를 기록합니다. 동일한 플랫폼·월·지표·검색어는 중복 기록되지 않습니다. 기존 값을 고치려면 **근거 → 수정**을 사용하세요. 게시물별 값과 계정 합계 또는 중복 주제를 함께 합산하지 마세요.

플랫폼·지표·월·관심 여부·검색으로 필터링할 수 있고, **소재로**를 누르면 현재 조건의 관측 값과 근거가 경험·소재함에 저장됩니다. JSON 일괄 입력은 화면에 표시된 공통 스키마만 지원합니다. 네이버·유튜브·Meta의 원본 파일을 자동 해석하는 기능은 아닙니다. **설정·데이터의 JSON 백업에는 유입 기록과 관심 주제도 포함됩니다.**

실제 계정 데이터는 자동으로 수집하지 않습니다. 데이터가 없는 항목은 0으로 처리하지 않으며, 조사 후보는 인기 검증 결과와 구분됩니다. 입력하지 않은 검색어와 비공개·소량으로 누락된 검색어는 분석에 포함되지 않습니다. 관심 주제 교집합과 정렬은 같은 플랫폼·지표 안의 기록만 사용하며, 전체 시장 규모·수익·미래 성과는 추정하지 않습니다.

## 공개 조사 결과

2026년 11월 3일 확인한 공개 자료를 바탕으로 9개 주제 후보를 추가했습니다. **공개 조사 결과**에서 플랫폼과 관심 주제로 필터링하고, 각 카드의 **확인 범위·원문 출처**를 펼쳐 확인하세요. **소재함에 저장**하면 출처·한계·추가 조사 항목이 함께 저장됩니다.

이 내용은 편집 후보이며 실제 계정 유입, 월간 검색량 또는 플랫폼별 인기 순위가 아닙니다. 네이버·인스타 직접 접근의 제한과 영어권·과거 유튜브 사례의 한계를 각 카드에 명시했습니다. 저장된 조사 스냅샷으로 자동 갱신되지 않습니다.

## 채널별 관심 주제

**채널별 관심 주제**에서 블로그·유튜브·인스타를 선택합니다. 블로그는 기독교·박진영·이단·다문화 가정·싱가포르·이민·애국·보수, 유튜브는 민폐 사건·인도/파키스탄 사건·토론·중국 관련 사건·레슬링·바디캠·공포·범죄·결혼/연애 사건을 기본 배치했습니다. 인스타는 별도 목록이 정해질 때까지 양쪽 주제를 함께 배치했습니다.

별 버튼은 해당 채널의 관심 여부만 바꿉니다. **전체 주제 배치**에서 다른 채널에도 추가하거나 끌 수 있습니다. 관심사에서 **소재 메모 만들기**를 누르면 채널과 편집 메모가 저장되고, 이후 원고 틀 생성 시 해당 채널이 기본 선택됩니다. 기존 원고는 자동 수정하지 않습니다. 결혼/연애와 레슬링의 세부 범위는 미정으로 유지했습니다.

이전 데이터는 첫 실행 시 채널 구분을 추가하며 원고·유입 기록·직접 수정한 주제 이름과 기존 관심 해제 상태는 보존합니다. 계정 연결·조사 결과·실제 유입 데이터가 새로 생기는 업데이트는 아닙니다.
